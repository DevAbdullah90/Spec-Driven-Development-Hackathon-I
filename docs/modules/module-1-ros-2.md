# Module 1: The Robotic Nervous System (ROS 2)

**Focus**: Middleware for robot control.

The Robot Operating System (ROS 2) acts as the nervous system for our physical AI, providing the foundational middleware necessary for real-time robotic control and communication.

## Core Concepts

*   **ROS 2 Nodes, Topics, and Services**: Understanding the distributed architecture that enables components to communicate asynchronously (Topics) and synchronously (Services).
*   **Bridging Python Agents to ROS controllers using `rclpy`**: Developing Python-based AI logic and connecting it securely to the underlying robotic hardware controllers.
*   **Understanding URDF (Unified Robot Description Format) for humanoids**: Learning how to define the kinematic and dynamic properties of the humanoid robot within the simulation environment.
