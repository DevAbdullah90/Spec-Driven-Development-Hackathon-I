# Module 3: The AI-Robot Brain (NVIDIA Isaac™)

**Focus**: Advanced perception and training.

This module focuses on the NVIDIA Isaac platform, the industry standard for developing and deploying AI-powered robots, serving as the robot's sophisticated brain.

## Key Technologies

*   **NVIDIA Isaac Sim**: Utilized for photorealistic simulation, providing high-quality environments and synthetic data generation for robust model training.
*   **Isaac ROS**: Focuses on hardware-accelerated components, including **VSLAM (Visual SLAM)** for simultaneous localization and mapping, and high-performance navigation routines.
*   **Nav2**: The standard ROS 2 navigation stack, tailored here for path planning and executing complex bipedal humanoid movement sequences in simulated space.

:::warning
NVIDIA Isaac Sim is an Omniverse application requiring **RTX-enabled GPUs**.
:::
